# Smart DoF 회의 정리 및 후속 작업

- 회의일: 2026-07-27
- 기준 자료: 회의 전사 및 현재 Smart DoF V9·V10 결과물
- 논문 투고 목표일: 2026-08-18
- 주의: 전사에는 일부 음성 인식 오류가 있으므로 일정과 고유명사는 필요 시 재확인한다.

## 1. 이번 회의의 핵심 결론

현재 Smart DoF는 사용자가 지정한 롯데마트를 선명하게 유지하고 주변을 흐리게 만드는 객체 중심 연출까지 구현되었다. 그러나 지금 결과에서는 롯데마트와 실제로 비슷한 깊이에 있는 주변 건물이나 차량이 서로 다른 정도로 흐려질 수 있다.

이것은 시선을 특정 객체에 모으는 효과로는 설명할 수 있지만, 일반적인 카메라의 기본 DoF로 설명하기에는 물리적으로 부자연스럽다. 일반적인 카메라에서는 센서와 거의 평행한 하나의 초점면이 형성되므로, 같은 깊이에 있는 피사체는 화면의 좌우 위치와 무관하게 비슷한 선명도를 가져야 한다.

따라서 다음 순서로 개발 방향을 바로잡는다.

1. 깊이맵을 기반으로 한 기본 DoF를 먼저 정확히 구현하고 검증한다.
2. 기본 DoF가 정상적으로 작동하는 결과를 기준 영상으로 확보한다.
3. 그 위에 Tilt/Swing 방식의 기울어진 초점면을 창의적 연출 옵션으로 추가한다.
4. 이후 날씨·시간대 등의 기존 영상 변환 기능과 함께 사용자 선택형 파라미터로 통합한다.

즉, 현재 결과를 틸트 효과라고 사후 해석하는 것이 아니라, 기본 DoF와 Tilt/Swing을 명확히 분리해 각각 의도적으로 구현해야 한다.

## 2. 반드시 구분해야 할 개념

### 2.1 기본 DoF

- 카메라 앞의 특정 깊이에 초점을 맞춘다.
- 초점면은 기본적으로 이미지 센서와 평행하다.
- 같은 깊이에 있는 픽셀은 화면의 왼쪽·오른쪽 위치와 관계없이 유사한 CoC와 블러를 받아야 한다.
- 초점 깊이에서 앞뒤로 멀어질수록 블러가 연속적으로 증가해야 한다.

### 2.2 Tilt와 Swing

- 렌즈의 방향을 바꿔 초점면 자체를 기울이는 연출이다.
- Tilt는 일반적으로 초점면을 위·아래 방향으로 기울이는 동작이다.
- Swing은 일반적으로 초점면을 좌·우 방향으로 회전시키는 동작이다.
- 서로 다른 깊이에 있는 롯데마트와 육교 같은 대상을 하나의 기울어진 초점면 위에 동시에 둘 수 있다.
- 이때 같은 깊이에 있던 다른 물체가 초점면에서 벗어나 흐려지는 것도 의도된 결과가 될 수 있다.

### 2.3 Shift

- 렌즈 또는 이미지 위치를 평행 이동해 건축물의 수직선과 원근을 교정하는 기능이다.
- 초점면을 기울이는 Tilt/Swing과 목적이 다르다.
- 서비스 이름이나 대중적 설명에서는 `Tilt-Shift`라는 표현을 사용할 수 있지만, 기술 문서와 논문에서는 `Tilt/Swing focal-plane control`과 `Shift perspective correction`을 구분하는 편이 정확하다.

### 2.4 확정된 솔루션의 전체 흐름

솔루션은 하나의 영상을 입력받아 사용자가 원하는 공간과 분위기를 다시 연출하는 사용자 제어형 영상 후처리 시스템으로 구성한다.

1. 사용자가 영상을 입력한다.
2. 시스템이 깊이, 객체, 카메라 움직임 등 장면 정보를 분석한다.
3. 사용자가 특정 객체 또는 공간상의 초점면을 선택한다.
4. DoF 엔진이 선택된 초점 기준에 따라 자연스러운 심도를 렌더링한다.
5. 사용자는 필요에 따라 Tilt/Swing, 날씨 변화, 시간 변화 모드를 조절한다.
6. 시스템이 프레임 간 일관성을 유지하면서 최종 영상을 렌더링한다.

이때 기능은 다음처럼 구분한다.

- `Natural DoF`: 센서와 평행한 기본 초점면을 사용하는 기준 모드
- `Tilt/Swing DoF`: DoF 엔진 안에서 초점면의 방향을 기울이는 공간 연출 모드
- `Weather Transformation`: 날씨와 대기 상태를 변경하는 독립 모드
- `Time Transformation`: 시간대와 이에 따른 색·조명 분위기를 변경하는 독립 모드

Tilt/Swing은 기본 DoF 결과 위에 블러를 다시 추가하는 필터가 아니다. 기본 DoF와 동일한 렌더링 엔진을 사용하되, 평행 초점면을 사용자가 지정한 기울어진 3D 초점면으로 교체하는 방식이다. 날씨와 시간 변화는 DoF와 별도로 활성화하거나 함께 조합할 수 있는 모듈로 설계한다.

## 3. 현재 구현 상태에 대한 판단

### 구현된 부분

- 사용자가 영상에서 관심 객체와 포인트를 지정할 수 있다.
- MobileSAM으로 관심 객체의 의미 영역을 구한다.
- Optical Flow로 프레임 간 타깃을 추적한다.
- Depth Anything 기반 깊이맵으로 상대 깊이 차이를 계산한다.
- 깊이 차이에 따라 공간 가변 블러를 적용한다.
- 타깃이 사라진 뒤 약 1.5초 동안 Deep Focus로 전환하는 포커스 풀링이 구현되었다.
- V10에서는 블러 강도가 이전보다 더 연속적으로 증가하도록 개선되었다.

### 현재 가장 중요한 한계

- 객체 마스크를 선명도 결정에 강하게 사용하면서, 같은 깊이의 비선택 영역이 불필요하게 흐려질 수 있다.
- 따라서 `선택 객체 강조 효과`와 `물리적으로 자연스러운 기본 DoF`가 섞여 있다.
- 깊이맵의 정확도를 영상만 보고 판단하고 있어, 같은 깊이 영역의 수치적 일관성이 아직 검증되지 않았다.
- 현재의 상대 깊이와 카메라 모델만으로 실제 렌즈와 동일한 물리적 CoC라고 주장하기는 어렵다.
- Tilt, Swing, Shift가 코드·UI·설명에서 아직 별도 모드로 정의되어 있지 않다.

## 4. 지금부터 진행할 작업

## P0. 기본 DoF 기준선 구현

가장 먼저 해야 할 작업이다.

### 구현 원칙

- V10은 비교 기준으로 보존하고 새 버전에서 작업한다.
- 객체 마스크는 초점 깊이를 안정적으로 추정하는 용도로만 사용한다.
- 최종 픽셀의 선명도는 객체 소속 여부가 아니라 깊이 차이로 결정한다.
- 동일하거나 유사한 깊이의 픽셀에는 유사한 CoC가 적용되어야 한다.
- 블러 강도는 `깊이 차이 → 데드존 → 연속 곡선 → CoC/블러 반경` 순서로 계산한다.
- 기존의 시간적 깊이 안정화, 마스크 안정화, 포커스 풀링은 유지하되 기본 DoF 원칙과 충돌하는 부분은 분리한다.

### 산출물

1. 원본 영상
2. 깊이맵 영상
3. CoC 또는 블러맵 시각화 영상
4. 평행 초점면 기반 기본 DoF 영상
5. `원본 / 깊이맵 / 기본 DoF` 비교 영상
6. 현재 V10과 새 기본 DoF의 비교 영상

### 검수 기준

- 롯데마트와 비슷한 깊이에 있는 주변 건물·차량이 비슷한 선명도를 갖는다.
- 초점 깊이 앞뒤의 블러가 끊기지 않고 연속적으로 증가한다.
- 도로의 깊이 변화가 블러맵에 자연스럽게 반영된다.
- 객체 경계에 halo, 번짐, 깜빡임이 없다.
- 타깃 이탈 후 포커스 풀링이 끊기지 않는다.
- 깊이맵의 오류가 결과 영상의 어느 부분에 영향을 주는지 설명할 수 있다.

## P1. Tilt/Swing 초점면 프로토타입

기본 DoF가 검증된 다음 구현한다.

### 사용자 입력 방식

초기 프로토타입에서는 자동 연출보다 명확한 사용자 제어를 우선한다.

- 방식 A: 영상에서 초점에 포함할 3개 지점을 선택
- 방식 B: 초점 기준점 1개와 Tilt·Swing 각도를 조절
- 방식 C: 서로 다른 깊이의 두 객체를 선택하고 두 객체를 통과하는 초점면을 계산

첫 구현은 세 점으로 3D 초점면을 정의하는 방식이 가장 명확하다.

### 계산 구조

1. 프레임별 깊이와 카메라 내부 파라미터를 이용해 픽셀을 3D 점으로 역투영한다.
2. 선택한 세 점의 3D 좌표로 초점 평면을 계산한다.
3. 각 픽셀의 3D 위치와 초점 평면 사이의 거리를 계산한다.
4. 이 거리를 CoC 또는 블러 반경으로 변환한다.
5. Optical Flow 또는 카메라 모션을 이용해 초점면과 CoC의 시간적 일관성을 유지한다.
6. 깊이 레이어와 가림 관계를 고려해 전경·배경 경계의 halo를 줄인다.

### 데모 장면

- 롯데마트와 육교를 동시에 초점면에 포함시키는 Swing 예시
- 도로 표면을 따라 초점이 이어지는 Tilt 예시
- 기본 DoF와 Tilt/Swing DoF를 한 화면에서 비교하는 예시

## P2. 사용자 선택형 연출 시스템으로 통합

서비스의 방향은 AI가 영상의 의도를 전부 자동 결정하는 방식보다, 사용자가 연출 의도를 선택하고 시스템이 계산과 렌더링을 담당하는 방식으로 잡는다.

### 권장 모드

1. Natural DoF
   - 평행 초점면
   - 실제 카메라와 유사한 기본 심도 표현

2. Object Focus
   - 선택 객체의 가독성과 집중도를 우선
   - 현재 V9·V10 계열 기능

3. Tilt/Swing Focus
   - 사용자가 기울어진 3D 초점면을 설계
   - 미니어처 또는 선택적 공간 강조 연출

4. Deep Focus Return
   - 타깃 이탈 또는 사용자가 지정한 시점에 자연스럽게 전체 초점으로 복귀

### 공통 조절 파라미터

- 초점 대상 또는 초점 평면
- DoF 강도
- 조리개 프리셋
- 최대 블러 반경
- 초점 전환 시작 시점
- 초점 전환 시간
- 전환 곡선
- Tilt 각도
- Swing 각도
- 초점면 두께
- 시간적 안정화 강도

### 후속 확장 파라미터

- 날씨
- 시간대
- 조명 분위기

이 확장 기능들은 핵심 DoF가 안정된 뒤 하나의 영상 연출 시스템으로 연결한다.

### 권장 시스템 구조

```text
영상 입력
   ↓
장면 분석
깊이 추정 · 객체 인식 · 추적 · 카메라 움직임
   ↓
초점 연출
객체 선택 또는 초점면 선택
   ↓
DoF 렌더링
Natural DoF 또는 Tilt/Swing DoF
   ↓
분위기 연출
날씨 변화 · 시간 변화
   ↓
시간적 안정화 · 경계 보정 · 최종 출력
```

사용자는 모든 값을 직접 설정할 수도 있고 프리셋을 선택할 수도 있다. AI의 역할은 사용자의 연출 의도를 대신 결정하는 것이 아니라, 선택한 의도가 영상 전체에서 안정적으로 유지되도록 깊이·추적·렌더링 계산을 수행하는 것이다.

## P3. 논문 구조 확정

투고 목표일까지 시간이 짧으므로 서비스 전체를 논문 범위에 넣지 않는다. 논문의 기술적 질문을 하나로 좁힌다.

### 권장 연구 질문

`단안 주행 영상에서 장면의 3D 구조에 고정된 초점면을 사용해, 화면 좌표 기반 블러보다 공간적으로 타당하고 시간적으로 안정적인 선택 초점 영상을 만들 수 있는가?`

### 권장 기여점

1. 장면에 고정되는 3D 초점면
2. 카메라 이동 중에도 안정적인 시간적 CoC
3. 가림 관계를 고려한 비생성형 블러 렌더링
4. 원본 픽셀과 객체 정체성을 보존하는 사용자 제어형 후처리

### 비교군

- 2D 선형/그라디언트 블러
- 프레임별 깊이 기반 기본 DoF
- 시간 안정화가 추가된 깊이 기반 DoF
- 객체 마스크 중심 V10
- 제안하는 3D 초점면 + 시간 안정화 + 가림 인지 렌더링

### 정량 평가

- 같은 3D 평면에서 CoC 분산을 측정하는 초점면 정합도
- Optical Flow 대응점 간 CoC 차이를 측정하는 시간 안정성
- 객체 경계 밖으로 블러가 번지는 경계 누출
- 선명 영역의 SSIM, LPIPS, edge consistency
- 처리 시간과 메모리 사용량

### 정성 평가

- 자연스러움
- 초점 의도의 명확성
- 경계 품질
- 카메라 이동 중 안정성
- Tilt/Swing 연출의 유용성

## P4. 특허 방향 정리

단순히 깊이맵으로 블러를 적용하는 기능만으로는 권리 범위가 약할 수 있다. 특허는 개별 알고리즘 하나보다 다음을 연결한 시스템 흐름으로 검토한다.

- 영상에서 사용자가 객체 또는 공간상의 지점을 선택
- 선택 정보를 3D 초점면 또는 시간축상의 초점 경로로 변환
- 깊이와 카메라 움직임을 이용해 초점면을 장면에 고정
- 가림 관계와 시간 일관성을 고려해 블러를 렌더링
- 여러 객체 사이의 초점 이동과 Deep Focus 복귀를 편집

## 6. 다음 회의에서 보여줄 최소 결과

다음 시연은 2026년 7월 29일 Zoom 화면 공유로 진행한다. 입력 영상과 초점 대상은 기존과 동일한 주행 영상 및 롯데마트를 사용한다.

1. 동일한 입력과 타깃을 사용한 기본 DoF 결과
2. 롯데마트와 비슷한 깊이의 주변 영역이 함께 선명하다는 근거
3. 깊이맵과 CoC 맵
4. 현재 V10과 기본 DoF의 차이를 설명하는 비교 영상
5. 동일한 입력 영상에 Tilt/Swing 초점면을 실제로 적용한 영상
6. 이후 `Natural / Object / Tilt-Swing` 세 모드로 발전시키는 로드맵

발표는 반드시 다음 이야기 순서를 유지한다.

`지난 결과의 문제 → 왜 기본 광학 원리와 충돌하는가 → 기본 DoF로 어떻게 바로잡았는가 → 기본만으로 밋밋한 영상을 Tilt/Swing으로 어떻게 연출할 것인가 → 논문과 서비스로 어떻게 확장할 것인가`

## 7. 확정 사항과 남은 연구 판단

### 확정 사항

- 시연 일시: 2026년 7월 29일
- 시연 방식: Zoom 화면 공유
- 입력 영상: 기존과 동일한 주행 영상
- 기본 초점 대상: 롯데마트
- 필수 시연 결과: Natural DoF 영상과 Tilt/Swing DoF 영상
- 서비스 방향: 객체 또는 초점면을 사용자가 정하고, DoF·Tilt/Swing·날씨·시간 변화를 의도대로 조절하는 시스템

### 개발 과정에서 판단할 사항

1. 롯데마트와 `같은 깊이`라고 검증할 비교 영역을 깊이맵에서 어떻게 선정할지
2. Tilt/Swing 시연에서 롯데마트와 함께 초점면에 포함할 두 번째·세 번째 지점을 어디로 정할지
3. 논문에서 3D Tilt/Swing 초점면을 핵심 제안으로 삼고 나머지 모드를 서비스 확장으로 둘지

수요일 시연은 `왜 이전 결과가 기본 DoF와 달랐는가 → 정상적인 Natural DoF → 의도적으로 초점면을 기울인 Tilt/Swing DoF → 사용자가 여러 연출 모드를 조합하는 최종 솔루션` 순서로 구성한다.
