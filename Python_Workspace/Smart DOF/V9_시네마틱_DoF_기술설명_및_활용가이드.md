# Smart DoF V9: 시네마틱 DoF 기술 설명 및 활용 가이드

## 한 줄 소개

Smart DoF V9는 사용자가 지정한 피사체를 선명하게 유지하고, 장면의 거리와 객체 경계를 AI로 추정해 주변을 자연스럽게 흐리게 만드는 **객체·뎁스 인지형 시네마틱 DoF 렌더링** 기술이다.

사용 경험 측면에서는 아이폰 시네마틱 모드처럼, 촬영 후에도 “어디에 시선을 둘 것인가”를 지정해 초점 연출을 만드는 방식에 가깝다.

## 영상 생성 흐름

### 1. 초점 대상 지정

사용자는 첫 프레임에서 선명하게 유지할 대상을 지정한다. V9에서는 단일 점뿐 아니라 다음 정보를 함께 사용한다.

- 대상 내부의 추적점
- 대상 전체를 포함하는 영역 박스
- 대상임을 알려 주는 긍정 포인트
- 도로·인접 물체처럼 제외할 부분을 알려 주는 부정 포인트

이 방식은 단순히 로고의 한 글자나 특정 픽셀을 추적하는 것이 아니라, 건물·인물·차량처럼 **객체 전체를 초점 대상으로 정의**하는 데 목적이 있다.

### 2. 객체 분할: MobileSAM

MobileSAM이 프레임마다 선택 대상의 외곽을 분할해 마스크를 생성한다. 이 마스크로 대상 내부는 선명하게 보호하고, 대상 밖으로 갈수록 블러가 증가하도록 만든다.

경계에는 feathering을 적용해 선명 영역과 블러 영역 사이가 딱 잘린 것처럼 보이지 않도록 한다.

### 3. 상대 거리 추정: Depth Anything

Depth Anything은 단일 영상 프레임에서 장면 내부의 상대적인 거리 관계를 예측한다. 이를 이용해 대상과 비슷한 거리의 주변은 비교적 선명하게 남기고, 초점 거리와 차이가 커지는 영역은 점진적으로 흐리게 만든다.

V9의 블러는 다음 두 정보를 결합한다.

- 선택 대상과의 상대 깊이 차이
- 선택 대상의 경계에서 떨어진 공간적 거리

따라서 단순한 일괄 배경 블러가 아니라, 선택한 객체를 중심으로 시선이 모이는 연출이 가능하다.

### 4. 객체 추적: Optical Flow

Lucas–Kanade Optical Flow로 선택한 추적점의 프레임 간 이동을 추적한다. 전진·역방향 추적 결과를 서로 대조해 신뢰도가 낮은 추적을 감지한다.

SAM은 기본적으로 2프레임마다 실행하며, 중간 프레임에서는 Optical Flow 이동량으로 최근 마스크를 이동시켜 사용한다. 이는 객체 경계의 연속성을 유지하면서 처리 시간을 줄이기 위한 설계다.

## 자연스러운 렌즈 연출을 위한 V9 개선점

### 연속적인 블러맵

이전 버전에서는 도로·차량·육교처럼 서로 다른 영역의 블러가 만나는 곳에서 경계가 필터 자국처럼 보일 수 있었다. V9는 블러 신호를 강하게 선택하는 방식 대신 부드럽게 합성한다.

```text
상대 깊이 차이
→ 초점 주변 선명 영역(dead zone)
→ smoothstep 기반의 점진적 블러 곡선
→ 객체 바깥 거리 기반 블러
→ 넓은 영역의 블러맵 smoothing
→ 대상 내부 선명도 재보호
```

이 과정으로 블러 강도의 차이는 유지하면서도 경계가 갑자기 바뀌는 느낌을 줄인다.

### 타깃 유실 후 포커스 풀링

선택 대상이 프레임에서 사라지면 V9는 즉시 효과를 끄지 않는다.

```text
대상 추적 정상
→ 마지막 안정 마스크와 초점 깊이 유지
→ 추적 유실 감지
→ 마지막 대상 마스크를 잠시 유지
→ 현재 프레임 깊이 정보로 블러맵 재계산
→ 약 1.5초간 cosine easing으로 블러 강도 감쇠
→ Deep Focus로 자연스럽게 복귀
```

이를 통해 화면이 갑자기 원본처럼 바뀌는 대신, 카메라가 초점을 넓게 다시 잡는 듯한 전환을 의도한다.

## 기술 구성

| 구성 요소 | 사용 기술 | 역할 |
| --- | --- | --- |
| 객체 분할 | MobileSAM | 사용자가 선택한 대상의 객체 마스크 생성 |
| 깊이 추정 | Depth Anything | 장면 내부의 상대 거리 추정 |
| 객체 추적 | Lucas–Kanade Optical Flow | 대상의 프레임 간 위치 변화 추적 |
| 마스크 안정화 | EMA·모션 워핑 | 마스크 깜빡임과 떨림 완화 |
| 블러 연출 | 거리 기반 feathering·smoothstep·다단 가변 블러 | 자연스러운 DoF 블러맵 생성 |
| 전환 연출 | Cosine easing | 대상 유실 후 부드러운 Deep Focus 전환 |

## 실제 렌즈와의 관계

V9는 조리개, 센서 크기, 초점거리 등을 완전하게 계산하는 물리 기반 광학 시뮬레이터는 아니다. 대신 AI가 객체와 거리 정보를 이해해 실제 렌즈 연출에 가까운 시각적 결과를 만드는 후처리 렌더링 방식이다.

정확한 표현은 다음과 같다.

> 객체·뎁스 인지형 시네마틱 DoF 렌더링

## 사용자 활용 흐름

1. 사용자가 영상을 업로드한다.
2. 화면에서 선명하게 유지할 대상 하나를 선택한다.
3. 필요하면 대상 전체를 박스와 보조 점으로 지정한다.
4. AI가 대상 추적, 거리 추정, 배경 블러, 포커스 전환을 수행한다.
5. 원본과 시네마틱 결과를 비교한 뒤 저장한다.

## 활용 가능 분야

- 차량 주행·블랙박스 영상에서 특정 건물, 차량, 표지판 강조
- 여행·브이로그 영상에서 인물 또는 랜드마크 중심의 숏폼 제작
- 부동산·상권·관광 홍보 영상에서 핵심 장소로 시선 유도
- 광고·브랜드 영상의 시네마틱 후반 연출
- 일반 스마트폰 영상에 사후 초점 연출 적용
- 안전·관제 영상에서 특정 객체의 시각적 강조

## 향후 고도화 방향

- 여러 인물·차량 중 초점 대상을 자동 전환하는 기능
- 사용자가 전환 시점과 전환 시간을 직접 편집하는 기능
- 조리개값처럼 이해하기 쉬운 블러 강도 프리셋
- 유리, 반사, 가림 상황에서의 객체 분할 안정화
- GPU·모바일 최적화를 통한 처리 시간 단축
- 카메라 메타데이터를 이용한 물리 기반 CoC 근사

## 현재 단계의 의미

V9는 단순 배경 흐림 필터를 넘어, 사용자가 “무엇을 보게 할 것인가”를 직접 정하고 AI가 그 의도에 맞춰 영상을 연출하는 후처리 기능의 기반을 제시한다.
